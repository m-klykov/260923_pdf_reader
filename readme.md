# PDF Reader F1

Библиотека для извлечения и структурирования данных из официальных PDF-отчетов FIA Формулы-1.

## Перечисления (Enums)

### `SessionType`
Определяет тип гоночной сессии:
* `P1`, `P2`, `P3` — свободные заезды (Practice 1–3).
* `Q` — квалификация (Qualifying).
* `SQ` — спринт-квалификация (Sprint Shootout).
* `S` — спринт (Sprint Race).
* `R` — гонка (Race).

### `DocType`
Определяет тип обрабатываемого документа FIA:
* `CLASSIFICATION` — классификация сессии.
* `MAXIMUM_SPEEDS` — максимальные скорости.
* `BEST_SECTOR_TIMES` — лучшие времена по секторам.
* `RACE_CONTROL_MESSAGES` — сообщения дирекции гонки.
* `SECTOR_ANALYSIS` — покруговой анализ секторов.
* `LAP_TIMES` — времена кругов (для заездов и квалификаций).
* `TRACK_ANALYSIS` — анализ нахождений на трассе.
* `LAP_ANALYSIS` — анализ кругов гонки.
* `FASTEST_LAPS` — лучшие круги гонки.
* `HISTORY_CHART` — график истории гонки.
* `PIT_STOP_SUMMARY` — сводка пит-стопов.
* `LAP_CHART` — диаграмма кругов.
* `DRIVERS_CHAMPIONSHIP` — положение в личном зачете.
* `CONSTRUCTORS_CHAMPIONSHIP` — положение в Кубке Конструкторов.

---

## Конвертер `PdfConvF1Base`

Основной класс-конвертер документов Формулы-1.

### Параметры инициализации
* **`session_type`** (`SessionType`): тип гоночной сессии.
* **`doc_type`** (`DocType`): тип входящего отчета.

### Метод `convert`
Выполняет конвертацию указанного PDF-файла.

* **Аргументы:** `pdf_path` (`str`) — путь к файлу PDF.
* **Возвращаемое значение:** список объектов `TableWrapper`.

## Пример использования

```python
from pdf_reader.pc_f1_base import PdfConvF1Base, SessionType, DocType

# Инициализация конвертера для итогового протокола первой практики
converter = PdfConvF1Base(
    session_type=SessionType.P1,
    doc_type=DocType.CLASSIFICATION
)

# Запуск обработки PDF-файла
tables = converter.convert("data/2026_14_esp_f1_p1_timing_classification_v01.pdf")
```

## Структура результата (`TableWrapper`)

Метод `convert` возвращает список объектов `TableWrapper`. Каждый такой объект представляет отдельную извлеченную таблицу из PDF-документа.

### Свойства
* **`title`** (`str`): заголовок таблицы (например, название сессии, имя и номер пилота или наименование сектора).

### Методы получения данных
* **`get_rows()`** -> `List[Dict[str, str]]`  
  Возвращает список строк таблицы, где каждая строка представлена словарем формата `{"ИМЯ_КОЛОНКИ": "ЗНАЧЕНИЕ"}`.
* **`get_table()`** -> `List[List[str]]`  
  Возвращает двумерный массив (матрицу) строк. Первая строка содержит названия всех уникальных колонок таблицы, последующие строки — очищенные значения ячеек.

### Пример обработки результата

```python
for table in tables:
    print(f"Заголовок таблицы: {table.title}")
    
    # Способ 1: Получение данных в виде списка словарей
    rows = table.get_rows()
    for row in rows:
        print(row)
        
    # Способ 2: Получение данных в виде матрицы (двумерного массива)
    matrix = table.get_table()
    headers = matrix[0]
    data = matrix[1:]
```

## Сводка по типам документов (`DocType`)

Описание структуры данных, возвращаемых методом `convert()` в зависимости от типа документа: количество таблиц, их заголовки (`title`) и список доступных полей (колонок).

---

### 1. `DocType.CLASSIFICATION`
Возвращает **1 таблицу**.
* **Заголовок (`title`):** `"Classification"`
* **Поля в зависимости от `session_type`:**
  * **Практики (`P1`, `P2`, `P3`):**  
    `pos`, `no`, `driver`, `entrant`, `time`, `laps`, `gap`, `int`, `kmh`, `time_of_day`.
  * **Квалификация (`Q`):**  
    `pos`, `no`, `driver`, `entrant`, `q1_time`, `q1_laps`, `q1_proc`, `q1_dtime`, `q2_time`, `q2_laps`, `q2_dtime`, `q3_time`, `q3_laps`, `q3_dtime`.
  * **Гонка (`R`):**  
    `pos`, `no`, `driver`, `entrant`, `laps`, `time`, `gap`, `int`, `kmh`, `fastest`, `on`, `pts`.  
    *(Если в документах присутствуют классифицированные и неклассифицированные пилоты, они объединяются в одну таблицу; для `NOT CLASSIFIED` поле `pos` заполняется пустой строкой).*

---

### 2. `DocType.MAXIMUM_SPEEDS`
Возвращает **до 4 таблиц** (по точкам замера максимальной скорости).
* **Заголовки (`title`):**  
  1. `"Speed Trap"`  
  2. `"Finish Line"`  
  3. `"Intermediate 1"`  
  4. `"Intermediate 2"`
* **Поля:** `pos`, `no`, `driver`, `kmh`.  

---

### 3. `DocType.BEST_SECTOR_TIMES`
Возвращает **до 3 таблиц** (по секторам трассы).
* **Заголовки (`title`):**  
  1. `"Sector 1"`  
  2. `"Sector 2"`  
  3. `"Sector 3"`
* **Поля:** `pos`, `no`, `driver`, `time`.  

---

### 4. `DocType.RACE_CONTROL_MESSAGES`
Возвращает **1 таблицу** 
* **Заголовок (`title`):** `"Race Control Messages"`
* **Поля:** `time`, `message`.

---

### 5. `DocType.SECTOR_ANALYSIS`
Возвращает **список таблиц**, по одной на каждого пилота.
* **Заголовок (`title`):** номер и имя пилота "3 Max VERSTAPPEN"
* **Поля:** `lap`, `s1_time`, `s1_kmh`, `s2_time`, `s2_kmh`, `s3_time`, `s3_kmh`, `time`.

---

### 6. `DocType.LAP_TIMES`
Возвращает **список таблиц**, по одной на каждого пилота.
* **Заголовок (`title`):** номер и имя пилота "3 Max VERSTAPPEN"
* **Поля:** `no` (номер круга), `p` (позиция на круге), `time` (время круга).

---

### 7. `DocType.TRACK_ANALYSIS`
Возвращает **список таблиц** (анализ времени нахождения на трассе по пилотам/транспондерам).
* **Заголовок (`title`):** номер и имя пилота "3 Max VERSTAPPEN"
* **Поля:** `transponder`, `pit exit`, `laps`, `pit entry`.

---

### 8. `DocType.LAP_ANALYSIS`
Возвращает **список таблиц**, по одной на каждого пилота (покруговой анализ гонки).
* **Заголовок (`title`):** номер и имя пилота "3 Max VERSTAPPEN"
* **Поля:** `lap`, `p` (позиция), `time` (время круга).

---

### 9. `DocType.FASTEST_LAPS`
Возвращает **1 таблицу**.
* **Заголовок (`title`):** `"Fastest Laps"`
* **Поля:** `pos`, `no`, `driver`, `entrant`, `time`, `on`, `gap`, `int`, `kmh`, `time_of_day`.

---

### 10. `DocType.HISTORY_CHART`
Возвращает **список таблиц**, по одной на каждый круг гонки.
* **Заголовок (`title`):** `"Lap 1"`, `"Lap 2"`, `"Lap 3"` и т.д.
* **Поля:** `no` (номер машины), `gap` (отрыв), `time` (время).

---

### 11. `DocType.PIT_STOP_SUMMARY`
Возвращает **1 таблицу** (сводка со всех страниц объединена).
* **Заголовок (`title`):** `"Pit Stop Summary"`
* **Поля:** `no`, `driver`, `entrant`, `lap`, `time_of_day`, `stop`, `duration`, `total`, `time`.

---

### 12. `DocType.LAP_CHART`
Возвращает **1 таблицу**.
* **Заголовок (`title`):** `"Lap Chart"`
* **Поля:** первая колонка — `POS`, последующие — номера позиций: `1`, `2`, `3`...).
* Значения для пос "GRID", "LAP 1", "LAP 2", ...
* В колонках с номерами позиций - бортовой номер гонщика

---

### 13. `DocType.DRIVERS_CHAMPIONSHIP`
Возвращает **1 таблицу** (положение в личном зачете пилотов).
* **Заголовок (`title`):** `"Drivers Championship"`
* **Поля:** 
  * `pos`, `driver`, `total`
  * Динамические пары колонок по этапам: `<КОД_ГРАН_ПРИ>` (очки) и `<КОД_ГРАН_ПРИ>_place` (занятое место). Например: `AUS`, `AUS_place`, `CHN`, `CHN_place` и т.д.

---

### 14. `DocType.CONSTRUCTORS_CHAMPIONSHIP`
Возвращает **1 таблицу** (положение в Кубке Конструкторов).
* **Заголовок (`title`):** `"Drivers Championship"`
* **Поля:**
  * `pos`, `entrant`, `total`
  * Динамические тройки колонок по этапам (так как у команды по 2 пилота): `<КОД_ГРАН_ПРИ>` (очки за этап), `<КОД_ГРАН_ПРИ>_pl1` (позиция 1-й машины), `<КОД_ГРАН_ПРИ>_pl2` (позиция 2-й машины).
